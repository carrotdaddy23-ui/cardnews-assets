칸 (위에서부터 채운다)

칸 넣는 값 메모
A 도매 표시가 1688·알리바바 표시가 (위안 또는 달러) 사양이 같은 상품인지 먼저 확인. 싼 값이 다른 사양이면 쓰지 않는다
B 환율 오늘 환율 × 1.03 여유분 3%
C 물류·관세·통관 배수 처음엔 1.4로 가정, 실제 견적 받으면 교체 해상 LCL·관세·통관·국내 운송 묶음
D 개당 원가 A × B × C
E 판매가 경쟁 상품 실거래가 (최저가와 중간값 둘 다) 가격비교 사이트 표시가
F 판매·결제 수수료 스마트스토어 판매 2.73% + 네이버페이 1.98~3.63% (넉넉히 6.63%로 잡아도 된다) / 쿠팡 판매 8~10.8% + 물류비 2025-06 개편 기준
G 택배비 무료배송이면 셀러 부담 (예: 3,000원)
H 포장비 실측 (예: 500원)
I 개당 마진 E - D - (E × F) - G - H
J 마진율 I ÷ E

C칸 펼쳐보기 (수입 원가: 배송비·관세·인증)

처음엔 C를 1.4로 두고 시작한다. 견적이 하나씩 오면 아래 칸을 채워 진짜 배수로 바꾼다. 한 번 들여올 때 전체 금액으로 적고, 마지막에 수량으로 나눈다.

칸 넣는 값 메모
P 상품값 합계 A × B × 수량
C1 중국 내륙 운송 공장 → 포워더·배대지 창고 판매자가 무료로 보내주는지 먼저 묻는다
C2 구매대행·배대지 수수료 업체 견적 (보통 상품값의 몇 %) 직접 결제·직접 포워딩이면 0
C3 국제 운송 해상 LCL은 부피(CBM) 기준, 특송(항공)은 무게(kg) 기준 가볍고 비싼 건 특송, 크고 싼 건 해상
C4 관세 (P + C3) × 관세율 관세율은 품목(HS코드)마다 다르다. 관세청 UNI-PASS 품목분류에서 확인. 한중 FTA 원산지증명서가 있으면 협정세율(더 낮거나 0)을 받을 수 있다
C5 부가세 (P + C3 + C4) × 10% 과세사업자는 나중에 매입세액으로 돌려받는다. 원가에선 빼고, 통관할 때 낼 현금으로만 준비한다
C6 통관·국내 운송 관세사 수수료 + 항구·공항 → 내 창고 포워더 견적에 묶여 오는 경우가 많다
C7 인증비 시험비 ÷ 이번 수량 전기·배터리·무선(블루투스)·어린이·식품 닿는 물건은 들여오기 전에 확인. 시험비는 모델당 한 번이라 수량으로 나눈다
진짜 C (P + C1 + C2 + C3 + C4 + C6 + C7) ÷ P 이 값으로 위 C칸 1.4를 바꾼다

인증 대상인지 모르면 키워드 '인증' 자료(KC 체크)를 먼저 본다. 판매할 물건은 개인 자가사용 통관(소액 면세)으로 들여오면 안 된다. 사업자 수입신고로 들여온다.

계산 방법 예시 (가상 숫자, 방법만 보세요)

상품 ¥20짜리 500개, 환율 195원/위안 가정.

  • P 상품값: 20 × 195 × 500 = 1,950,000원
  • C1 내륙 운송: 개당 100원 → 50,000원
  • C2 구매대행 5% → 97,500원
  • C3 해상 LCL → 150,000원
  • C4 관세 8% 가정: (1,950,000 + 150,000) × 8% = 168,000원
  • C5 부가세: 226,800원 (돌려받으니 원가에서 뺀다)
  • C6 통관·국내 운송 → 150,000원
  • C7 인증 시험비 600,000원 가정 ÷ 500개
  • 합계 3,165,500원 → 개당 6,331원, 진짜 C = 1.62

같은 물건인데 인증이 필요 없으면 개당 5,131원, C = 1.32. 인증이 필요해도 1,000개를 들여오면(해상 운송은 부피만큼 300,000원) 개당 5,581원, C = 1.43 (시험비는 그대로라 수량이 늘수록 개당 부담이 준다). 그래서 인증 품목은 첫 발주 수량부터 다시 정한다.
